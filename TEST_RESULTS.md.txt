## Ограничения

Проверен локальный учебный прототип. Данные хранятся в оперативной памяти. Реальная интеграция с ФНС, постоянная база данных, авторизация и остальные методы API пока не реализованы.
## Тестирование загрузки вложений — POST /attachments

Дата: 23.10.2026

| № | Сценарий                                    | Ожидаемый результат                                 | Фактический результат        | Статус |
| 1 | Загрузка PNG допустимого размера            | 201 Created                                         | 201, возвращён attachmentId  | PASS |

**Ограничения учебного прототипа:**
- Данные о вложениях хранятся в оперативной памяти.
- Файлы сохраняются в локальную папку `uploads`.
- Проверяется расширение файла, но не подтверждается его реальный формат и содержимое.
- Авторизация и связь вложения с конкретной заявкой пока не реализованы.
## Идемпотентность — POST /applications

| № | Сценарий | Ожидаемый результат | Фактический результат | Статус |
| 1 | Создание заявки с новым `Idempotency-Key` | 201 Created | 201 | PASS |
| 2 | Повтор с тем же ключом и теми же данными | Возвращается прежний `applicationId` | 201, тот же результат | PASS |
| 3 | Повтор с тем же ключом, но изменённым телефоном | 409 Conflict, `IDEMPOTENCY_KEY_REUSED` | 409 | PASS |

**Ограничение:** идемпотентность реализована в учебном прототипе на основе оперативной памяти. Сохранность данных после перезапуска сервера и конкурентные запросы отдельно не проверялись.
## Проверка сохранности данных после перезапуска

| Параметр | Значение |

| Idempotency-Key | `restart-test-001` |
| ID до перезапуска | `3b0030f0-263e-4aeb-860e-8068e04867a9` |
| ID после перезапуска | `f6508354-b9a4-46f1-af7c-55f7676101d4` |
| HTTP-код после перезапуска | `201 Created` |
| Результат | Повторный запрос создал новую заявку |

**Вывод:** идемпотентность реализована только в рамках текущего запуска приложения. После перезапуска данные из оперативной памяти теряются. Для сохранения идемпотентности между перезапусками требуется постоянное хранилище, например PostgreSQL.

Статус: **PASS — подтверждено ожидаемое ограничение учебного прототипа.**
